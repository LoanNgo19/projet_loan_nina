# RACI - Application de gestion de voyages de vacances

## Légende
- R = Responsable : réalise la tâche
- A = Accountable : décide et valide
- C = Consulté : donne son avis
- I = Informé : suit sans intervenir

## Tableau RACI

| Tâche | Moi | Binôme | Client / Utilisateur |
|---|---|---|---|
| Définir le besoin du projet | A | R | C |
| Rédiger la fiche signalétique | A / R | R | I |
| Choisir la stack technique | A | R | C |
| Concevoir l’architecture du projet | A | R | I |
| Créer la maquette / wireframe | C | A / R | C |
| Développer le front-end | R | A / R | I |
| Développer le back-end | R | A / R | I |
| Gérer la base de données | A | R | I |
| Tester les fonctionnalités | C | A / R | I |
| Corriger les bugs | R | A / R | I |
| Vérifier le budget / coût du projet | A | R | I |
| Valider le produit final | A | C | R |
| Rédiger le cahier des charges | A / R | R | C |
| Préparer la présentation finale | A | R | C |

## Version simplifiée pour le binôme

| Tâche | Moi | Binôme |
|---|---|---|
| Analyse du besoin | A / R | R |
| Prototypage | C | A / R |
| Développement front-end | R | A / R |
| Développement back-end | C | A / R |
| Tests | C | A / R |
| Validation finale | A | R |

## Comment l’utiliser
- La personne avec la lettre A est celle qui décide.
- Les personnes avec la lettre R font le travail.
- Les personnes avec C sont consultées.
- Les personnes avec I sont informées du bon avancement.

## Exemple d’application pour ce projet
- Moi : gestion du projet, validation fonctionnelle, documentation, cadrage
- Mon binôme : conception technique, développement, tests, corrections
- Client : validation du produit final et validation des besoins

Cette répartition permet d’avoir une bonne organisation, une meilleure collaboration et un suivi clair des responsabilités.
