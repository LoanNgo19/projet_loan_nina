# projet_loan_nina

## Fiche signalétique du projet : application de gestion de voyages de vacances

### 1) Identification du projet
- Nom du projet : VoyagePlanner / VacancesManager
- Type : Application web et mobile de gestion de voyages
- Objectif principal : Centraliser la planification, le suivi et la gestion des voyages de vacances pour une meilleure organisation avant, pendant et après le séjour.

### 2) Problème à résoudre
Les voyageurs ont souvent du mal à :
- organiser les détails d’un voyage (dates, budget, destinations, réservations),
- suivre les dépenses,
- garder les documents importants au même endroit,
- planifier les activités à faire,
- gérer les voyages en famille ou en groupe.

L’application doit permettre de centraliser toutes ces informations dans un seul espace.

### 3) Objectifs
- Préparer un voyage facilement et rapidement.
- Suivre le budget et les dépenses.
- Gérer les réservations et les documents.
- Organiser les activités et les itinéraires.
- Avoir une vue d’ensemble de ses voyages.
- Gérer plusieurs destinations et plusieurs voyages à la fois.

### 4) Public cible
- Particuliers
- Couples
- Familles
- Groupes d’amis
- Utilisateurs qui planifient plusieurs voyages dans l’année

### 5) Fonctionnalités principales
#### A. Gestion des voyages
- Ajouter un nouveau voyage
- Définir la destination, les dates, le type de séjour
- Choisir le statut du voyage : en préparation, en cours, terminé

#### B. Budget
- Définir un budget total
- Saisir les dépenses : transport, hébergement, restauration, loisirs
- Suivre les dépenses en temps réel
- Afficher les montants restants

#### C. Réservations
- Gérer les billets d’avion/train
- Ajouter les réservations d’hôtel
- Gérer les locations de voiture
- Stocker les confirmations et les numéros de réservation

#### D. Documents
- Enregistrer les documents importants
- Pièces d’identité
- Billets
- Assurances
- Vignettes / visas
- Notes personnelles

#### E. Activités et itinéraire
- Planifier les visites, excursions et activités
- Ajouter des lieux à visiter
- Organiser une journée par journée
- Gérer les itinéraires et temps de trajet

#### F. Checklist avant départ
- Valider les tâches de préparation
- Vérifier les bagages
- Vérifier les documents
- Vérifier les réservations

#### G. Souvenirs / journal de voyage
- Ajouter des photos
- Noter des impressions
- Ajouter des mémos de voyage

### 6) Modules de l’application
- Dashboard principal
- Gestion des voyages
- Gestion du budget
- Gestion des réservations
- Gestion des documents
- Planification d’activités
- Checklist de départ
- Journal de voyage
- Notifications / rappels

### 7) Utilisateurs et rôles
- Utilisateur standard : créer et gérer ses voyages
- Gestionnaire de voyage : organiser les réservations et les dépenses
- Administrateur (si version plus avancée) : gérer les comptes, paramètres, données système

### 8) Exigences fonctionnelles
- Création, modification et suppression d’un voyage
- Ajout de plusieurs dépenses par voyage
- Calcul automatique du total dépensé
- Gestion de plusieurs destinations
- Ajout de commentaires ou notes
- Sauvegarde des informations persistantes
- Recherche et filtrage des voyages

### 9) Exigences non fonctionnelles
- Interface simple, claire et intuitive
- Adaptation mobile et desktop
- Sécurité des données personnelles
- Sauvegarde automatique
- Performance rapide
- Compatibilité avec plusieurs navigateurs

### 10) Modèle de données
Les informations principales à stocker :
- Utilisateur
- Voyage
- Destination
- Date de départ / retour
- Budget
- Dépense
- Réservation
- Hébergement
- Transport
- Activité
- Document
- Note / souvenir

### 11) Idées de fonctionnalités avancées
- Alertes de budget
- Suggestions de destination selon les préférences
- Synchronisation avec calendrier
- Importation de devis ou de confirmations
- Partage de voyage entre plusieurs personnes
- Export PDF du voyage

### 12) Technologie recommandée
Pour une première version, on peut utiliser :
- Frontend : React / Next.js / Vue
- Backend : Node.js / Express ou Python / Django
- Base de données : PostgreSQL ou MySQL
- Authentification : Firebase ou JWT
- Stockage de fichiers : Supabase ou Google Drive / stockage cloud

### 13) Description courte du projet
“Une application qui aide les utilisateurs à organiser leurs voyages de vacances, suivre leur budget, gérer leurs réservations, leurs documents, leurs activités et leurs souvenirs dans un seul espace simple et pratique.”
